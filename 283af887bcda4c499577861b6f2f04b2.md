# Design Specification: Giridhar Reddy Portfolio (Brutalist Minimalist)

Foundational design tokens and rules for a personal portfolio optimized for signal over decoration. Every decision serves one goal: make the work impossible to ignore.

## 1. Vibe & Intent
- **Core Principle**: Brutalist minimalism. Raw structure as aesthetic.
- **Aesthetic**: Signal execution, not polish. No gradients, no shadows, no glassmorphism, no decorative elements of any kind.
- **Visual Language**: High contrast, sharp edges, warm off-white base. Whitespace is intentional, not padding.
- **Audience**: Founding teams and operators at early-stage startups. They read fast. Every element must earn its place.

## 2. Typography
- **Primary Font**: Inter (Sans-Serif)
- **Label/Metadata Font**: Geist Mono — used exclusively for labels, tags, status indicators, and technical metadata
- **Type Scale**: Strict 1.250x (Major Third)
  - **H1 Display**: 48px / 1.1 LH / 800 weight / -0.02em tracking
  - **H2 Header**: 32px / 1.2 LH / 700 weight / -0.01em tracking
  - **H3 Subheader**: 24px / 1.3 LH / 600 weight
  - **Body Primary**: 16px / 1.6 LH / 400 weight
  - **Body Secondary**: 14px / 1.5 LH / 400 weight
  - **Mono Label**: 12px / Geist Mono / uppercase / 0.08em tracking

## 3. Color Palette
| Token | Value | Usage |
| :--- | :--- | :--- |
| `color-bg-base` | #F7F5F2 | Primary background — warm off-white, never pure white |
| `color-bg-surface` | #EDEBE7 | Cards, secondary sections |
| `color-text-primary` | #0A0A0A | All headers, primary body copy |
| `color-text-secondary`| #6B6B6B | Metadata, captions, descriptions |
| `color-accent` | #2563EB | Active nav states and "Active" status badges ONLY. Not for buttons or decorative use. |
| `color-border-base` | #0A0A0A | Structural 1px borders |
| `color-border-muted` | #D4D0C8 | Card outlines, secondary dividers |

## 4. Spacing & Grid
- **Base Unit**: 8px
- **space-tight**: 8px — internal component padding
- **space-medium**: 24px — component to component
- **space-generous**: 64px — section to section
- **Rule**: Whitespace creates separation. No decorative dividers unless content demands data density.

## 5. Borders & Effects
- **Border Radius**: 0px on all containers. 4px maximum on inputs only. No exceptions.
- **Strokes**: 1px solid only.
- **Shadows**: None. Zero. Separation is achieved via background contrast and borders only.
- **No gradients** anywhere in the system.

## 6. Component Rules
- **Buttons**:
  - **Primary**: #0A0A0A fill, white text, 0px radius, no shadow, high-weight label
  - **Secondary**: white fill, #0A0A0A 1px border, 0px radius, no shadow
- **Cards**: #EDEBE7 background, 1px border #D4D0C8, no shadow, 0px radius
- **Nav**: Active state uses #2563EB underline only. No background fill on active nav items.
- **Status badges**: Geist Mono, uppercase, 12px. Active = #2563EB text on #EDEBE7 background.
- **Inputs**: 1px border, 4px radius max, no glow on focus — use 2px border color change instead.
