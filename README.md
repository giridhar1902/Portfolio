# Portfolio

A personal portfolio built with Next.js App Router.

## Design System

Strictly Brutalist Minimalist:
- 1px borders
- High-contrast typography
- No animations, shadows, or background gradients
- Inter (sans-serif) for primary text
- Space Mono (monospace) for secondary text and details
